# Solución al Desafío de Frontend Mentor: Landing Page de Fylo con Diseño de Dos Columnas

![Badge](https://img.shields.io/badge/Estado-Completado-brightgreen)  
Este es mi solución al desafío **Fylo Landing Page with Two Column Layout** de Frontend Mentor. El objetivo era crear una landing page estática y responsiva con un diseño de dos columnas, utilizando **HTML**, **CSS** y **SASS**.

**Desafío de Frontend Mentor:** [Fylo Landing Page](https://www.frontendmentor.io/challenges/fylo-landing-page-with-two-column-layout-5ca5ef041e82137ec91a50f5)  
**Live Demo:** [Ver Proyecto en Vivo](https://omargarcia21.github.io/fylo-landing-page-with-two-columns.github.io/)

## Descripción del Proyecto

Este proyecto es una landing page estática que presenta información sobre un servicio ficticio llamado **Fylo**. La página incluye:

- Un **header** con un diseño atractivo y un menú de navegación.
- Una sección principal con un diseño de **dos columnas** que combina texto e imágenes.
- Una sección de **características** que describe los beneficios del servicio.
- Un **footer** con enlaces útiles y redes sociales.

El diseño es completamente responsivo, utilizando **CSS Flexbox** y **CSS Grid** para organizar los elementos de manera eficiente y visualmente atractiva. Además, se utilizó **SASS** para modularizar y organizar los estilos.

## Tecnologías Utilizadas

- **Lenguajes de Programación**: HTML, CSS.
- **Preprocesador CSS**: SASS para una gestión más eficiente de los estilos.
- **Metodologías CSS**: Flexbox y Grid para la disposición de los elementos.
- **Diseño Responsivo**: Compatible con dispositivos móviles, tablets y desktop.

## Instrucciones de Instalación y Uso

Este proyecto es una página web estática, por lo que no requiere instalación.
